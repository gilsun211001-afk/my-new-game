# 임창민 게임 기획 포트폴리오

- `index.html` — 포트폴리오 사이트 (단일 파일, 버튼형 메뉴)
- `games/castle-survival/index.html` — 플레이 가능한 프로토타입

## 공개하기 (GitHub Pages)
Settings → Pages → Branch를 `main` / `(root)`로 지정하면 `https://gilsun211001-afk.github.io/my-new-game/` 에서 열립니다.

## 수정 위치
`index.html` 하단 `<script>`의 `CONFIG`(이메일·폴더 링크), `NOTION`, `REVIEWS`, `JOSEON_DOCS` 배열만 고치면 됩니다.

## 공개 전 체크
- 노션 `app.notion.com/p/...` 링크는 각 페이지에서 "웹에 게시"를 켜야 외부인이 열 수 있습니다.
- Google Drive 문서는 "링크가 있는 모든 사용자"로 공유해야 합니다. 팀 문서는 팀 동의 후 공개하세요.
